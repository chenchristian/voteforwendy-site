# voteforwendy.com — static site

Static snapshot of the Wendy Huang for Congress (CA-14) campaign site, mirrored from the
live WordPress installation and restructured to run on GitHub Pages (no PHP/MySQL backend).

- Source: mirrored from `voteforwendy.com` (previously hosted on SiteGround/WordPress) on 2026-09-13.
- Hosting: GitHub Pages, custom domain via the `CNAME` file.
- Known limitations: the built-in WordPress search box and the Jetpack "Like" button are
  decorative only — both required a live WordPress backend that no longer exists here.

To update content going forward, edit the HTML files directly (there is no CMS/admin panel
for this static copy).
